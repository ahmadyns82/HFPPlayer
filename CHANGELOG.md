## [1.0.0] - 2026-05-02
### Added
- Folder browser — browse music by directory
- Song list with search, artwork, artist, duration
- Full player screen — seek bar, shuffle, repeat, volume
- Mini player bar visible across all tabs
- Lock screen & Control Centre integration
- Background audio playback
- Optional Bluetooth HFP/SCO routing mode (Settings toggle)
- Supports Apple Music library + Files app (Documents folder)
- GitHub Actions CI — builds on every push/PR
